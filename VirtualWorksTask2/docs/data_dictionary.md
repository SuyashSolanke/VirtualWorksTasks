# Data Dictionary — NexaFlow Analytics Churn Dataset

**Source:** Hugging Face (`arti199919/synthetic-saas-churn-sample`)  
**Database:** PostgreSQL (`users` account table + `user_monthly` monthly time-series table)

---

## Table 1: `users` (Account Level)

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `user_id` | `VARCHAR(100)` | `PRIMARY KEY` | Unique identifier for each customer account |
| `signup_date` | `DATE` | — | Date the customer signed up |
| `country` | `VARCHAR(50)` | — | Customer country |
| `company_size` | `INT` | — | Size of the customer's organization |
| `plan_type` | `VARCHAR(50)` | — | Subscription tier (`Starter`, `Pro`, `Business`, `Enterprise`) |
| `monthly_price` | `NUMERIC(10, 2)` | — | Account monthly price |
| `sessions_per_month` | `INT` | — | Account-level monthly sessions attribute |
| `feature_usage_score` | `NUMERIC(5, 2)` | — | Account-level feature usage score |
| `support_tickets` | `INT` | — | Account-level support ticket count |
| `payment_failures` | `INT` | — | Account-level payment failure count |
| `last_active_date` | `DATE` | — | Most recent date of user activity |
| `churned` | `INT` | — | Overall account churn flag (`1` = churned, `0` = active) |
| `churn_date` | `DATE` | — | Date of churn (if churned) |
| `tenure_months` | `INT` | — | Total tenure in months |
| `total_revenue` | `NUMERIC(12, 2)` | — | Cumulative revenue generated by the account |
| `ltv_12m` | `NUMERIC(12, 2)` | — | Projected 12-month customer lifetime value |
| `industry` | `VARCHAR(100)` | — | Customer industry segment |
| `acquisition_channel` | `VARCHAR(100)` | — | Marketing/sales channel (`organic`, `paid`, `partner`, `outbound`, `marketplace`) |
| `billing_period` | `VARCHAR(50)` | — | Billing cycle (`monthly` or `annual`) |
| `seats_purchased` | `INT` | — | Total seats purchased on the account |
| `discount_pct` | `NUMERIC(5, 2)` | — | Discount percentage applied to the account |
| `payment_method` | `VARCHAR(50)` | — | Payment method (`card`, `invoice`, etc.) |

---

## Table 2: `user_monthly` (Monthly Time-Series Level)

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `user_id` | `VARCHAR(100)` | `PRIMARY KEY` (part 1), `FOREIGN KEY -> users(user_id)` | Customer account identifier |
| `month` | `DATE` | `PRIMARY KEY` (part 2) | Monthly snapshot period |
| `tenure_month` | `INT` | — | Tenure month number for that snapshot |
| `plan_type` | `VARCHAR(50)` | — | Plan tier during that month |
| `monthly_price` | `NUMERIC(10, 2)` | — | Monthly price during that month |
| `mrr` | `NUMERIC(10, 2)` | — | Monthly Recurring Revenue in that month |
| `sessions` | `INT` | — | Number of sessions recorded in that month |
| `feature_usage_score` | `NUMERIC(5, 2)` | — | Feature engagement score in that month |
| `support_tickets` | `INT` | — | Support tickets logged in that month |
| `payment_failures` | `INT` | — | Failed payment attempts in that month |
| `churned` | `INT` | — | Churned during the current month (`1` / `0`) |
| `churned_next_month` | `INT` | — | Churned in the following month (`1` / `0`) |
| `nps_score` | `INT` | — | Net Promoter Score recorded in that month |
| `product_incident` | `INT` | — | Whether a product incident occurred (`1` = yes, `0` = no) |
| `active_seats` | `INT` | — | Active seats used during that month |
